# MoviePilot 清理媒体文件（Jellyfin 修复版）

基于 MoviePilot「清理媒体文件」v2.16 的个人兼容性修正版。

## 修复内容

修复 Jellyfin 删除整个媒体目录时，文件监控只收到目录删除事件，导致原插件没有继续进入文件级硬链接清理流程的问题。

修正版利用插件已有的 `file_state` 找出该目录下原先记录的文件，并继续调用原有的文件删除处理流程，因此保留 v2.16 原有的延迟删除、inode/device 硬链接判断、硬链接同步清理、STRM 监控、刮削文件处理、转移记录处理及重新硬链接保护逻辑。

## 安装

在 MoviePilot 插件市场/插件仓库设置中添加本 GitHub 仓库，使用 `main` 分支。

## 注意

请不要同时启用原版「清理媒体文件」和本修正版，避免两个插件同时监控相同目录。

本项目是个人兼容性修复，不代表 MoviePilot 官方插件。
